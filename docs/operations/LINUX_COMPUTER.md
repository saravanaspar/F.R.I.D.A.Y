# Linux desktop automation

The old FRIDAY X11 provider is retired from the standard plugin configuration. Follow the upstream [Cua Driver Linux installation guide](https://github.com/trycua/cua/blob/main/docs/content/docs/how-to-guides/driver/install.mdx) for a desktop session, AT-SPI support, the driver daemon, and `cua-driver doctor`. Then run `friday setup cua` to verify FRIDAY can connect to its MCP tools.

See [FRIDAY's CUA integration](../CUA.md) for browser and native window use.
